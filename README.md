# EX No.3.2. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION
## DATE:
## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1.To form the centre dome, choose create sketch and choose front view and draw a circle of radius 110mm and draw a rectangle of length 120mm and breadth 60mm from the centre point of the circle.

<img width="357" height="222" alt="image" src="https://github.com/user-attachments/assets/fa81b267-d055-4739-b88e-9edcf0e15197" />
<img width="330" height="257" alt="image" src="https://github.com/user-attachments/assets/68453371-0162-42c9-901a-9b3e598d58db" />

2.Close the structure using line option.

 <img width="327" height="260" alt="image" src="https://github.com/user-attachments/assets/8dcb621a-da99-4d2d-97dc-ed6b6b754c8f" />

3.Trim the unnecessary sketches and form a dome with a rectangle opening at the front.

<img width="387" height="225" alt="image" src="https://github.com/user-attachments/assets/1e0cffeb-5d03-456a-bcb6-8e63b6ae9732" />

4.Now extrude the sketch to 150mm.

<img width="475" height="250" alt="image" src="https://github.com/user-attachments/assets/4e7fbb8e-7774-46ae-9d9b-5069f0089872" />

5.To create side bodies, create a plane from the centre of the dome  with the length 50mm using construct option then select the offset option and slide the plane with the length 50mm.

<img width="417" height="246" alt="image" src="https://github.com/user-attachments/assets/efaf8b34-5ea7-42f4-ba23-5d91c791d9d1" />

6.Give finish sketch.

<img width="295" height="237" alt="image" src="https://github.com/user-attachments/assets/78a5ad3e-2ad1-49b3-9c1d-f2cb035957d7" />

7.Give create sketch and select the new plane which was created now.

8.Draw a rectangle length 120mm and breadth 30mm and extrude the rectangle by 40mm.

9.Now give finish sketch and select create sketch thus choose top view.

10.Draw a circle of diameter 60mm using two point circle which connects the points of the rectangle as it makes a semicircle and trim the excess semicircle which is unnecessary. Again draw a circle of diameter 40mm at the centre of the bigger circle.

11.Now mirror the side sketch using the mirror option.

<img width="616" height="410" alt="image" src="https://github.com/user-attachments/assets/1aa83d0a-aeca-4288-b2d4-20a87e2a8ef2" />

12.Now extrude both the sketch for 30mm and using the extrude option make a hole at the centre circle which is of diameter 40mm.

13.Give finish sketch and select create sketch.

14.Choose top view and draw a circle at the centre of radius 10mm.

15.Using the extrude option, put a hole in it.

<img width="586" height="225" alt="image" src="https://github.com/user-attachments/assets/c5c59b99-c01f-4256-a4cb-817d5a42584e" />
